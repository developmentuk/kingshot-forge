# Render Engine User Guide

1. Select a benchmark and confirm its availability.
2. Choose a device profile and glyph family.
3. Adjust calibration and device overrides.
4. Upload approved reference artwork when comparison is required.
5. Use overlay mode to inspect alignment.
6. Save, export, or reset the local calibration profile.

Ready benchmarks have approved artwork. Metadata-only benchmarks remain unavailable for full visual validation until artwork is approved. Broken references are an Operations repair task.
