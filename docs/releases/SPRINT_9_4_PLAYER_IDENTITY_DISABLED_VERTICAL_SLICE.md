# Release 0.7.1 — Sprint 9.4 Player Identity disabled vertical slice

Sprint 9.4 implements a complete local Player Identity product path without enabling it. It adds production-shaped repositories/services, linked-character/limit/Primary/Active workflows, private and public routes, default-deny visibility and aliases, Gift/Art/Hero boundaries, support/four-eyes contracts, stable APIs/codes/events, read-only legacy classification, accessible responsive UI, privacy-safe analytics and a guarded replacement-schema proposal.

All twelve feature groups default OFF. Production persistence uses a disabled adapter; capabilities deny all. Ownership Verification remains OFF, no provider exists and no real character is verified. Synthetic fixtures are test-only. The replacement SQL is not a migration, requires a non-production marker and ends in `ROLLBACK`.

No Player Planning, Alliance authority, Gift provider/consent logic, Art moderation, canonical Hero redefinition, Codex A/B/D edits, Supabase writes, production grant/RLS/policy changes, migration application, deployment, merge or push are included.

Decisions still requiring Clark and Aegis approval include the replacement baseline/migration, persistence adapter, capability grants, public profile enablement, alias/visibility policy, verification provider/proof/expiry, support operations/retention, Hero Showcase limits and Gift eligibility policy.
