# Release 0.7.4 — Community Art Studio

## Scope

Community Art Studio is a complete player-to-moderation-to-gallery vertical slice. Players submit raster artwork, authenticated uploads remain private, authorised moderators review submissions, and only published records appear in the public gallery.

## Architecture and lifecycle

- Dedicated `community_art_submissions` storage-backed records reuse Forge authentication and permissions without touching legacy `submissions` or `favourites`.
- Lifecycle: `pending → approved → published`, or `pending → rejected`.
- The browser can upload into its own generated UUID path and insert only a pending submission. Moderation and publication are server-authoritative.
- The `community_art_public_gallery` projection excludes user IDs, moderator fields, private notes and storage paths.

## Image and attribution rules

- PNG, JPEG and WebP only; maximum 5 MiB; dimensions 128–4096 pixels per side.
- SVG and remote image URLs are rejected.
- Attribution is Forge display name, custom creator name, or anonymous. Profile attribution stores only the safe display name at submission time.
- Ownership and community-guideline confirmations are required.

## Permissions and privacy

- `contributions.submit` is represented by authenticated submission access; `moderation.manage` protects the Admin queue.
- Pending originals live in the private `community-art-submissions` bucket. Public users cannot list or read it.
- Public delivery uses short-lived signed URLs generated by the server for published records only.
- No service-role credential is shipped to browser code.

## Validation and limitations

`npm run check`, production build, existing Art Studio tests, SQL policy verification and Supabase security/performance advisors were run. Existing unrelated lint warnings remain unchanged. Browser visual validation and a signed-in end-to-end upload/moderation journey remain for Clark's local validation because this session has no authenticated browser account.

Auto Redeem, notifications, likes, comments, social features and unrelated schema remain out of scope.
