# Forge Vision Mapper — compatibility note

The earlier screen-specific Vision Mapper proposal has been superseded by the permanent **Forge Vision Platform Service** architecture.

Canonical reference: [`FORGE-VISION-PLATFORM.md`](FORGE-VISION-PLATFORM.md)

Mappings remain a core Forge Vision capability, but they are no longer framed as a Governor Profile/API-fallback feature. VISION-001 now establishes provider-neutral extractor plugins, governed Field Registry targets, immutable mapping versions, evidence, confidence, validation, conflict handling, confirmation and Vision Studio without any screen-specific implementation.
