# ADR-007 — Media Asset Identity

**Status:** Accepted for future implementation

An asset ID is stable across immutable asset versions. Original files, variants and crops are immutable and checksummed. Content uses explicit usage bindings with roles, ordering and publication state. Replacements create new versions; rollback selects an earlier published binding.

Public delivery is controlled and permission-aware. Direct uncontrolled image URLs are not a canonical content contract.
