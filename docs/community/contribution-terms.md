# Contribution terms

These terms are a project policy draft and require owner/legal review before activation.

Contributors retain ownership where appropriate. By submitting work for consideration, a contributor grants Forge permission to review, adapt and publish the submitted work within the project where accepted. Code contributions remain subject to the repository’s existing licence; this sprint does not choose a new software licence.

Contributors must have the rights needed for submitted code, writing, images, video, datasets and other material. Copied work without permission is not accepted. Forge should attribute accepted contributions in a reasonable way where appropriate. Unreleased material is confidential. A contributor may stop contributing, but accepted contributions may remain in the project under these terms and the applicable repository licence.

These are unpaid voluntary hobby/community roles and do not create an employment relationship.
