# Contributor role specifications

The canonical typed catalogue is `src/data/contributorRoles.ts`; the public views are `/join` and `/join/:roleSlug`. Each role includes purpose, activities, useful skills, experience, commitment, access/security considerations, questions and recruitment status.

All roles are unpaid, voluntary hobby/community roles. There is no employment relationship, guaranteed minimum hours, payment, future payment, equity, prize, qualification, guaranteed reference or guaranteed acceptance.

| Role | Category | Technical | Status |
| --- | --- | ---: | --- |
| Forge Programmer | Build | Yes | Open for interest |
| Forge Tester | Test | No | Open for interest |
| Community Champion | Community | No | Open for interest |
| Forge Contributor | Community | No | Open for interest |
| Data Curator | Content and Data | No | Open for interest |
| Content Contributor | Content and Data | No | Open for interest |
| Accessibility and UX Reviewer | Accessibility and Localisation | No | Open for interest |
| Translator and Localisation Contributor | Accessibility and Localisation | No | Planned |
| Community Moderator | Trust and Safety | No | Planned |
| Beta Tester | Test | No | Open for interest |

Moderation appointment, publishing permissions, administrator/owner access and production access are separate decisions. Acceptance into a contributor pathway must never grant them automatically.
