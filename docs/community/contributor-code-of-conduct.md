# Contributor Code of Conduct

Forge Contributors communicate respectfully and inclusively. Harassment, discrimination, threats, intimidation, doxxing and deliberate disruption are not accepted.

Contributors protect private information, unreleased features, credentials and project discussions. They use only the access needed for agreed work, report security concerns privately, attribute sources, submit original work or documented permission, and disclose conflicts of interest.

Community rules apply consistently. Sensitive moderation or safeguarding concerns should be escalated to the project owner through the configured project contact route. Access may be paused or removed when safety, confidentiality, security or conduct requires it. Contributors may step away voluntarily.
