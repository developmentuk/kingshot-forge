# Versioning

Kingshot Forge uses Semantic Versioning.

```text
MAJOR.MINOR.PATCH
```

## Major

Increase the major version for incompatible platform or product changes.

Example:

```text
1.0.0 → 2.0.0
```

## Minor

Increase the minor version for significant backward-compatible features or platform milestones.

Example:

```text
0.6.0 → 0.7.0
```

## Patch

Increase the patch version for backward-compatible fixes and small improvements.

Example:

```text
0.6.0 → 0.6.1
```

## Pre-1.0 Development

Before `1.0.0`, minor versions may contain substantial platform changes.

Release notes must clearly explain compatibility impact.

## Tags

Git tags include the `v` prefix:

```text
v0.6.0
```

## Milestone Naming

- `PM` — Platform Milestone
- `FM` — Feature Milestone
- `RM` — Release Milestone

Examples:

```text
PM2B — Editorial Workflow Platform
FM1 — Public Player Profiles
RM0.6.0 — Editorial Platform Release
```
